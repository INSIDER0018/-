# 自动播放雨课堂插件

一个用于 **雨课堂网课平台** 的 Chromium 浏览器扩展，自动顺序播放课程视频，支持静音，并规避切标签页时视频被自动暂停。

## 功能

1. **自动播放**：在左侧目录中自动点击视频，播放完整后自动跳转下一条，**跳过"作业/测试题"**。
2. **配置窗口**：点击扩展图标弹出面板，实时显示**当前网课名称**、**当前章节（第几节）**、**视频进度**。
3. **通用性**：适配雨课堂平台所有网课（不同学校、不同课程均可，如英语课等）。
4. **静音选项**：用户可自选是否静音播放（浏览器级静音，杜绝声音闪烁）。
5. **规避切标签页暂停**：覆写页面可见性状态，切到其他标签页时视频不停。

## 安装方法（Chromium 内核：Chrome / Edge / 其他）

1. 打开浏览器，进入扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 打开右上角 **「开发者模式」** 开关。
3. 点击左上角 **「加载已解压的扩展程序」**。
4. 选择本插件所在的文件夹（即包含 `manifest.json` 的 `自动播放雨课堂插件` 目录）。
5. 安装完成后，工具栏会出现扩展图标（蓝色 ▶）。

## 使用方法

1. 打开雨课堂网课的学习页（例如 `https://scut.yuketang.cn/.../studycontent` 或学习空间视频页）。
2. 点击工具栏中的插件图标，弹出配置面板。
3. 在面板中：
   - 查看当前**网课名称**和**当前节**。
   - 打开/关闭**静音**开关。
   - 点击 **「开始自动播放」** 按钮。
4. 插件会从当前视频开始，依次自动播放，完成后自动跳下一条，跳过测试题。
5. 需要停止时，再次点击 **「停止自动播放」**。

## 实现说明

- **视频条目识别**：`div.nav-item-leaf-box` 下的 `.leaf-item-tag` 文本为 `视频`。
- **测试题跳过**：同结构中 `.leaf-item-tag` 文本为 `作业`（自动跳过），另有 `讨论`、`考试` 也会跳过。
- **播放完成判定**：视频 `currentTime >= duration`，或右侧 `.control-right` 显示「已完成」。
- **课程名**：`.learning-space-header__primary`。
- **当前节**：当前激活视频（`.leaf-item.is-active`）所属 `.nav-item` 的 `.nav-item-node` 标题。
- **切标签页规避**：通过 manifest 的 `world: "MAIN"` 注入 `main-world.js`，覆写 `document.visibilityState` / `hidden` / `hasFocus`，并监听 `visibilitychange` / `blur` 恢复播放，另加 1 秒间隔兜底（隔离世界与主世界双重保险）。

## 注意事项

- 仅适用于 Chromium 内核浏览器（Chrome / Edge / 其他 Chromium 系）。
- **首次安装后必须刷新课程页面**，内容脚本才会注入；否则 popup 会提示「未检测到课程页」。
- 需停留在雨课堂的**学习页**（含左侧目录/视频播放器的页面，URL 形如 `.../ai-workspace/.../video/...`）。在课程列表页等其他页面会提示「未检测到课程页」。
- 本插件为个人学习辅助工具，请仅用于自己的账号和课程。

## 常见问题

- **提示「未检测到课程页」**：确认已打开网课学习页并刷新；内容脚本注入后需等目录渲染完成（通常 1~2 秒）。
- **点击开始后没反应**：打开浏览器开发者工具（F12）Console，查看是否有 `[雨课堂插件]` 日志；若无日志说明脚本未注入，请刷新页面。
